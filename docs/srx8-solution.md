> ### ⚑ 关键修正：相性「免疫」不减免伤害，只挡击破值
>
> 上面这张表在**修正一条硬规则之前**有两种读法是无解的。病根不是编队，是我把
> `TotalAttack.PHYSICAL/MAGICAL/ELEMENT` 里的 `2` 当成了「伤害归零」。**那个读法是错的**，
> 证据是数值自己打架：
>
> * 「死志的凝结」的 `Mode_A` 标着**法术免疫**，可它的**法抗只有 20**——
>   法抗 20 的含义恰恰是「法术打它相当有效」。一边说法术有效、一边说法术免疫，
>   只有「免疫 ≠ 伤害减免」才讲得通。
> * 吓人路灯是**法术免疫**，同时**法抗 99**。若免疫已经把伤害归零，99% 法抗就是废设；
>   两层防御各管一件事才合理。
> * 这些键全挂在 `TotalAttack.*` 命名空间下，而图鉴描述用的是
>   「弱点：X；**免疫**：Y」——与咆哮铳那句「受到**非弱点攻击**时……**弱点失效**」
>   并列，都是【击破/弱点系统】的词汇。
>
> 于是：`0 弱点` / `1 正常` / `2 免疫` 决定的是**这个伤害类型能不能累积击破值**，
> 伤害本身照常按 DEF/RES 结算（吓人路灯的法抗 99 会把法术压到 1%）。
>
> 修正后，原本在物免窗口里「没人打得动 BOSS」的死锁自然消失——
> 三种读法全部取胜。旧行为保留在 `sim(..., affinity_blocks_damage=True)` 里备查。
>

## 一、这一轮补上的治疗

博士说「加上治疗，可以用凯尔希思衡托二技能」，这条正中要害：旧版本里
真正的死因不是漏怪，而是**站在高台的人被隔几格点死**。

### 凯尔希·思衡托（`char_1052_kalts2`）槽2「保护性拒止」

技能描述与黑板逐字对得上，**全部可解析**：

```
attack@atk_scale  3.8   → 380%
heal_scale        2.0   → 回复目标周围友方 200% 攻击力
ammo             10     → 10 发弹药
sluggish          5.0   → 停顿 5 秒
atk               1.5   → 攻击力 +150%
range_id        y-11    → 攻击范围扩大
描述里的四个字：真实伤害
```

四处落地：

1. **真实伤害**——黑板里**没有**伤害类型字段，`atk_scale 3.8` 只说倍率。
   只能从描述里判。这条差两个数量级：按法术算，4,512 打在法抗 99 的
   吓人路灯身上只剩 45。判定收得很紧，全名册只有 3 条技能含"真实伤害"。
2. **治疗 200%**——`heal_scale` 与 `atk_scale` **并存**，同一击既打伤害又
   治疗，不是二选一。这一发 = 475 × 2.5 × 2.0 = **2,375 点**。
3. **停顿 5 秒**——不能移动，但**照样能开火**。这与眩晕、冻结不同，别混。
4. **10 发弹药**——打光进冷却，所以她的输出是脉冲式的，不是持续的。
   这也是她**顶替不了**予愿安洁莉娜的原因。

### 医疗的普通攻击也是治疗

判据取 `character_table` 的**特性文本**"恢复友方单位生命"，不按职业名推：
守望者（凯尔希）职业也是 MEDIC、特性同样以治疗开头，但它另外还会起飞。

规则落成一句话：**这一击打不打伤害**看技能有没有写攻击倍率（写了就是
"攻击变为什么什么"，把治疗改成了伤害）；**治不治疗**看技能有没有
`heal_scale`，没有则医疗干员的平A按 `1.0` 治疗。

### 天赋2「医者丰碑」也建模了

> 其他友方干员**进入自身攻击范围时**立刻获得 1 层护盾并额外获得一次
> **每秒回复 50 点生命值**的增益治疗，持续 **30 秒**（不可叠加）

「进入」有歧义：凯尔希 72s 才落地，而圣聆初雪 35s 就站在范围内了。
所以做了两档：

- **宽松**——光环落地当帧已在范围内的友方也算"进入"
- **严格**——只认光环落地**之后**才进场的友方

**两档结果完全相同**（79% / 全倍速胜）。说明这份治疗不是天赋给的，
而是**槽2 自己的 `heal_scale`**——正是博士指的那一条。歧义因此不影响结论。

未建模：护盾那一层（描述只写"1 层护盾"，没给数值）、【罗德岛】翻倍。
两处都偏**保守**——宁可把治疗算少，不把生存算多。

## 二、稳在哪里：两处，都要说清楚

### ① 站的格子让 BOSS 的停点永远落在覆盖里

BOSS「死志的凝结」沿 y=2 西行，一旦有人在它 2.6 格射程内就**原地停下开火**。
它的几何停点上限是 `x = 2.66`。

予愿安洁莉娜槽3 的范围是 `3-9`，而她有个规律：**站 `(x,4)` 朝右时，
y=2 这一行罩住 `[x, x+1, x+2]`**。所以站 `(1,4)` 朝右，罩的是 `[1,2,3]`
——**BOSS 无论停在哪一格都在里面**。这就是这一组全倍速不崩的原因。

旧答案站 `(11,4)` 朝左，罩的是 `[9,10,11]`；能打 BOSS 的只有圣聆初雪，
而她在 (2,4) 时 **y=2 这一行只罩得住 `(2, 2)` 一格**。停点偏一格她就够不着、
只能站着挨打——**一个 1 格宽的窗口**，这才是那张"92% 余量"的真相。

### ② 凯尔希槽2 把挨的打治回来

| | 圣聆初雪 末血 | 最低余量 |
|---|---|---|
| 三人（无治疗） | 784 / 2,058 | 38% |
| 加凯尔希槽2 | **2,058 / 2,058 满血** | **79%** |

她挨了 1,274 伤，凯尔希治回 1,274。数字对得上。

### 敌速敏感性（这是这套解的验收标准）

校准值来自 1-7 实机对齐，误差 1.4%。扫描区间取 0.85–1.5，远宽于误差：

```
×0.85 ×0.9 ×0.95 ×1.0 ×1.05 ×1.1 ×1.15 ×1.2 ×1.25 ×1.3 ×1.4 ×1.5
 胜    胜   胜    胜   胜    胜   胜    胜    胜    胜   胜   胜     ← A / B
 败    败   胜    胜   胜    胜   胜    败    败    败   败   胜     ← 旧答案
```

旧答案在 **0.85–0.9 与 1.2–1.4 全崩**，而且**非单调**（1.5 又赢）——
这正是"坐在悬崖上"的指纹：结果由 BOSS 落在哪一格决定，不是由强弱决定。

## 三、编队是怎么按"练度优先"挑的

全名册 211 人。**能单侧罩住 6/6 出生簇的只有 11 名**，按练度排：

| 名次 | 干员 | 分 | 单侧 6/6 摆放 | 结论 |
|---|---|---|---|---|
| 1 | 望 | 2812 | **做不到** | RANGED，唯一的路径格 (6, 7) 是地面，她站不上 |
| 2 | 圣聆初雪 | 2788 | (2,4) / (10,4) | **用** |
| 3 | 机械师 | 2696 | 地面位里练度最高且能站 (6, 7) | **用** |
| 4 | 凯尔希·思衡托 | 2638 | (2,4) / (10,4) | **阵亡**（三槽全试，166.6s 死）→ 改为治疗位 |
| 8 | 逻各斯 | 2506 | (10,4) 朝左**盖不到 x=11 那一列** | 出局 |
| 9 | 予愿安洁莉娜 | 2458 | (11,4)左 / (8,4)右 / (1,4)右 | **用**（第 4 名阵亡后，她是练度最高的可用者） |

第 4 名（凯尔希）为什么不能占高台：她是 MEDIC，2,043 血、低防，
在右侧出生簇的射程里**三个技能槽都在 166.6s 阵亡**。注意模拟对她还是
**偏袒**的——把她的治疗平A当伤害算了——就这样都站不住，所以排除是稳的。

地面位只有 `(6, 7)` 一格在敌人路径上；能站且阻挡 ≥2 的干员里，机械师练度最高。

## 四、边界

### 已建模

屏障、BOSS 重生、飞行不可阻挡、`lifePointReduce = 0`、击倒给费、
远程敌人停下开火、敌方按最后部署索敌、全场总攻击装置、P3R 击破与倒地、
技能（SP 回转 / 倍率 / 范围改写 / 弹药）、**治疗（平A / 技能 heal_scale /
天赋增益治疗光环）**、**停顿（sluggish）**、**技能改写的真实伤害**、
天赋、模组、信赖、专精。

### 未建模

- 元素损伤
- 敌方主动技能：BOSS `Skill_Revelation`（cd 30 / init 25 / `idle_duration` 5）、
  咆哮铳「炸膛」的弱点失效、吓人路灯屏障存在时的弱点失效
- 召唤物、嘲讽等级（星熊/塞雷娅的嘲讽 +1）
- 凯尔希天赋2 的护盾层与【罗德岛】翻倍

其中"弱点失效"那条可以量化：把全场总攻击装置**整个关掉**再跑，
仍然全胜、余量 59%。所以它翻不了盘。

### 复现

```bash
python tools/skland.py status      # 森空岛登录态（凭据在 ~/.skland/）
python tools/roster.py             # 名册 → data/skland/roster_<uid>.json
python tools/run_srx8.py --check   # 只做编队合法性校验
python tools/run_srx8.py --rank 40 # 按练度列候选
python tools/export_srx8.py        # 跑候选并导出 out/srx8-*.json（含敌速扫描）
```

`run_plan(..., speed_scale=...)` 是敌速敏感性开关，
`heal_mode="target"` 是「停顿/治疗范围」的严格读法。

### 仍然成立的四条工程判据

1. **干员口径必须走森空岛**。MAA OperBox 没有专精、模组、信赖。
2. **模组三道门**：`type != INITIAL` → `isSpecialEquip == False` →
   在 `battle_equip_table` 里。机械师的特勤证章在数据里 `type` 仍是
   `ADVANCED` **也带战斗数值**，唯一标志是 `specialEquipDesc`。
3. **落点合法性只能按 `character_table.position`（MELEE/RANGED）判**，
   不能按职业推。望与新约能天使都是 `RANGED`。
4. **MAA 协议**：`location` 的 y 自顶向下（`maa_y = 8 − y`）；
   `requirements.module` 是**编号 1–4**；`module_level`/`potential` 官方
   标注「暂不支持」；`skill_usage` 自动触发的技能填 0，手动填 1。
