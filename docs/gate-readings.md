> **这份台账记的是「一次完整的整闸读数」**：`tools/check_go_all.py --selfcheck` 在
> **某一棵具体的树**上、用**某一枚具体的仪器**、喂**具体的一批输入**跑出来的结果。
>
> 它存在的理由：这类读数此前散落在各分支文档里，而**引它的人看不出「这是哪一次、在什么上跑的」**。
> 本仓记过一条——**读数出错先分三个变量：固定尺子换对象／固定对象换尺子／工作区 vs 入库**。
> 这张表就是那三件套的落点。

## 一 · 一次读数必须带齐的四件

| 件 | 为什么 |
|---|---|
| **树**（`git log --oneline -1` 的 sha ＋ 是否干净） | 「工作区 vs 入库」是三个变量之一 |
| **仪器**（exe 路径 ＋ `sha256(16)`） | 不记仪器，将来绿红翻转时没人能判是**对象**变了还是**仪器**换了 |

## 三 · 第 1 次那条红**不是判据红**，而且它是个结构性事实

### ⚠ 先记住一条：「仪器 sha16」是**构建身份**，不是**源码身份**

本台账记的是 exe 的 `sha256(16)`。**同一份源码，在不同目录里构建，会得到不同的 sha。**
今晚实测（`rios-sim/` 自 `b65ac03` 起**一个字节没改**）：

| 构建在哪 | sha16 |
|---|---|
| 冻结树 `%TEMP%\gatechk` | `2cfca5eb487b3e0b` ← 本台账第 1–3 行记的就是它 |
| 主树 `rios-sim` | `f7cca5041e5a88b9` |
| 把 `rios-sim/` 拷到另一个临时目录再建 | `0e6e898ce58d3c0e` |

加 `-trimpath` **也没能让两棵树相等**（主树 `5ce12b5fcb8b5205` ／ 冻结树 `7533d5575a9b679e`）。

⇒ **推论三条**：

1. 这个 sha 回答的是「**是不是同一次构建**」，**不是**「**是不是同一份源码**」。
   跨树比较它**没有意义**；同树前后比较它才有意义（本台账第 1-3 行同树，所以可比）。
2. 想钉**源码**身份，要用**源码侧签名**（树 sha ＋ 源码内容签名），不能用 exe sha。
3. ★ **本台账每一行的 sha 只对本行那棵树有效** —— 「同一枚仪器」这句话，
   只在**同一棵树路径**下成立。

`干员 rc=3` 印的是：

> 真实练度·账号名册 **输入MISSING**（0 次折算未量到）⇒ 本轮不给判决；
> 真实练度·深扫 468/468、合成练度·全量宽扫 1324/1324 次折算逐字段一致

`rc=3` 是**仪器缺输入**，与 `rc=1`（判据红）**不是同一个码**。名册在 `.gitignore` 里
（个人数据、不入库）⇒ **闸门在彻底干净的检出上永远不会全绿**，
它的形态是「**25 绿 ＋ 1 具名缺输入（rc=3）**」。

★ 比原来那版好得多：原来「名册不在」会让那一段**静默不跑**、脚本照旧 `rc=0`
并印「468/468 一致」。**三态设计在这里第一次真正救了场**。

补拷名册之后，同一棵树、**同一枚仪器**，26/26 全绿 ⇒ 差的那一环自始至终**只有一个输入文件**。

## 四 · 怎么复现

```powershell
# 1) 建一棵冻结树（detached，**不建任何 junction**）
git worktree add --detach $env:TEMP\gatechk <sha>

# 2) 把输入**复制**进去（不是链接）
Copy-Item data "$env:TEMP\gatechk\data" -Recurse -Force
Copy-Item docs\roster-*.md "$env:TEMP\gatechk\docs\" -Force   # ← 少这一句就是 25/26

# 3) 在那棵树里自己 build，并用**它自己的**仪器
cd "$env:TEMP\gatechk\rios-sim"; go build -o "$env:TEMP\gatechk\out\acceptance\rios-sim-stage3.exe" .
$env:RIOS_SIM_BIN = "$env:TEMP\gatechk\out\acceptance\rios-sim-stage3.exe"

# 4) 跑
cd "$env:TEMP\gatechk"; python -X utf8 tools\check_go_all.py --selfcheck

# 5) 收尾：先删掉拷进去的 data，再摘 worktree（**不用 --force 兜**）
Remove-Item "$env:TEMP\gatechk\data" -Recurse -Force
git worktree remove "$env:TEMP\gatechk"
```

⚠ **绝不要用 junction 建冻结树**：2026-09-24 有人用 `git worktree remove --force`
收尾时**穿透 junction** 删掉了主仓 `data/` 的内容。收尾要先断链接再摘树。
