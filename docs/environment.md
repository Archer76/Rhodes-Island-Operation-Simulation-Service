# 关卡环境机制（战斗层）

`ak_tactic/battle/environment.py` + `tools/check_environment.py`。
文本层（把机制正文编译成公式项）见 `mechanics.md`，两者是**两层**：
那一层回答「这一关用了哪些机制、正文被形式化成了什么」，
这一层回答「机制跑起来是每秒掉多少血」。

第一个落地的消费者是**怀黍离的田地 / 病害值**。

## 一、三条事实来源，各自可分辨

| 来源 | 给出什么 | 取法 |
|---|---|---|
| 关卡 JSON `runes[key=env_system_new][].blackboard` | **五个数值参数** + 初始污染点 | `PolluteParams.from_stage` |
| prts.wiki「特殊机制」页 + 关卡页字段 | **公式的形状** | `mechanics.parse_mechanic` |
| 关卡 JSON `mapData` | **哪些格是田地** | `is_farmland` / `farmland_cells` |

两条来源互为校验：HS-8 页写「20+病害值×3 / 100+病害值×9」，
而黑板里正是 `basic_damage=20 / damage_ratio=3 / first_basic_damage=100 /
first_damage_ratio=9`。自检里有一条逐项对照钉住这个吻合。

## 二、黑板怎么读（踩过的真错）

黑板条目形如 `{"key":…, "value":<num>, "valueStr":<str|null>}`：

* **数值型键的值住 `value`**，`valueStr` 恒为 `null`；
* 只有 `init_pollut_value` 这类字符串住 `valueStr`。

只读 `valueStr` 会得出「五个参数全是 None」，并进而误判
「环境系统不在 gamedata 里」——**这个假结论在本项目真出现过**。
自检里因此有一条专门断言「数值键的 `valueStr` 是 None」。

## 三、⚠ 难度掩码：禁止取第一条，且 **`ALL` 必须认**

同一个 `env_system_new` 在关卡里常有多条，靠 `difficultyMask` 区分，
实测取值有三种：`NORMAL` / `FOUR_STAR` / **`ALL`**。

* 取第一条会静默画错污染点（`act31side_ex08`：NORMAL `1,1:0` vs
  FOUR_STAR `4,4:100`）；
* 只认 `NORMAL` 会**整条漏掉** `act31side_08`（它用的就是 `ALL`），
  而且不报错——环境伤害静默变成 0。

匹配规则：`mask == "ALL" or mask == 难度`。

## 四、坐标：`init_pollut_value` 的 row 要翻一次

格式 `"row,col:value"`，其 row 是**游戏内部口径（自下而上）**，
解析时翻一次 `y = 高 - 1 - row`（与 `routes[].row` 同规矩，见
记忆里的「地图不翻、路线翻」）。

自证：`act31side_08` 写 `7,1:100`，图高 9 → `y=1`；而该关情报写
「场地**左上角**田地区的初始病害值+100」，翻过来正是靠近顶部那一行。
不翻则落到 `y=7`，与情报相反。

## 五、田地判据（第三版，待实机校正）

```
田地 = heightType == "LOWLAND"  且  tileKey ∉ {tile_telin, tile_telout, tile_hole}
```

依据是 prts.wiki「田地」原文「仅适用于**地形标记**为**默认**的地面地块
（传送门出入口/地穴除外）」。

⚠ **必须按 `tileKey` 的名字判，不能只看字段。**
`tile_hole` / `tile_telin` / `tile_telout` 的
`(heightType, buildableType, passableMask)` 与普通低地**完全一致**，
字段分不出来。这不是理论顾虑：`act31side_08` 真有一条 5 格长的地穴竖墙，
只看字段会把它当成可通的田地，把本该分开的两片连成一片——
自检里有一条就断「地穴墙把田地切成 2 片」。

⚠ 反过来，`tile_start` / `tile_end` / `tile_fence_bound` / `tile_flystart`
**仍然是田地**。第一版自造过一个把它们也排掉的排除集，被博士的地图预览图证伪。

## 六、模型：谁共享什么

原文两句话是**分开**写的，所以粒度也不同：

* 「田地拥有【实际病害值】」 → **按格**（`actual: dict[cell, float]`）
* 「未被隔断的连片田地拥有共同的【最大病害值】」 → **按连通域**（`Field`）

这个区分不是抠字眼，是阻流阀那条规则逼出来的：「被隔断的组各自取当前
最高【实际病害值】作为新的【最大】」——若 `实际` 也按组存，
「各组当前最高」就无从谈起。

连通域用**四邻**：斜向相接的两格在游戏里不共享病害。

【缓存】是加在**【最大】**上的（原文「每 0.2s 释放 1 点**累加至当前的
【最大病害值】上**」），装置（泵站、天桩）走 `add_cache`。

## 七、⚠ 三处歧义（都留在代码里，没有偷偷选）

1. **靠拢步长有两种读法。** 原文「与最大值的差值每25点+1实际病害值，
   小数部分上入」：
   * **甲**（`base=1`，博士 2026-09-17 记录的口径，**当前实现**）：`ceil(差值/25 + 1)`
   * **乙**（`base=0`，原文直读）：`ceil(差值/25)`

   两者相差恰好 **1 点/秒**。改 `ACTUAL_BASE_STEP` 即可切换，两种读法都有自检盯着。

2. **初始播种的粒度。** 数据是「坐标 + 值」（`7,1:100`），当前实现把那一格的
   【实际】设为该值、把所属田地的【最大】抬到该值，**同组其余格子仍从 0 爬升**。
   另一种读法是整片播种（同组每格都从该值起）。开场那一秒差 320 点伤害。
   取逐格的理由是 `act31side_ex03` 给了**两个**点（`5,5:90|5,3:90`）而它们落在
   **同一片**田地里——整片播种会让第二个点冗余。**这个理由不是定论。**

3. **爬升是渐近的，不是恒速。** 步长 `ceil(差值/25+1)` 随差值缩小而变小，
   差值 100 时每秒 +5、差值 25 时 +2。实关实测：**30 秒才到 97，到不了 100**。
   （我第一版按恒速 5/秒 写过断言「20 秒后到 100」，跑出 77 才暴露——
   所以自检的判据是**逐秒对拍那条规律**，而不是某个秒数上的某个数。）

## 八、结算

```
病害值 = 0   →  每秒回复 hp_recovery_per_sec（恒 50）点生命
病害值 > 0   →  每秒受到 basic_damage + 实际病害值 × damage_ratio 的环境法术伤害
部署瞬间      →  额外受到 first_basic_damage + 实际病害值 × first_damage_ratio
```

原文两句分开写，所以**部署瞬间那一下是额外的，不是每秒结算的第一次**。

不作用于高地——这不需另判，田地判据本身就要求低地。

## 九、接进模拟器

`BattleSimulator(..., environment="auto" | "off", environment_difficulty=...)`。

* `auto`（默认）——这一关的 `runes` 里有环境系统就自动开启。
  **没有则一个对象都不建**，绝大多数关卡走这条，零开销。
* `off` —— 显式关掉，用于回归对照。

接线三处：构造时建 `FarmlandSystem`；`_do_deploy` 里结算部署瞬间那一下；
主循环 3.7 步 `_environment_tick` 里推进病害值并按整秒结算。

**伤害按整秒结算用整数计数而非 `>= 1.0` 后清零**：掉帧时 `dt` 可能跨过
不止一秒，只结一次等于把伤害漏掉。`fps=30` 时不会发生，但 `fps=1` 的粗扫会——
而粗扫正是搜索里用得最多的档。

### 接线的效果有多大（实关实测）

`act31side_08` 的有病害那片田地里**有 10 个可部署格**（`(10,3)` 一带）。
但它们在开场时【实际】为 0，按渐近规律爬升：1/10/20/30 秒 = 5/45/77/97 点，
对应每秒伤害 35/155/251/311。所以**站进去是先安全、后越来越疼**，
而不是一落地就吃满伤害——这个形状完全由第七条那处播种歧义决定。

## 十、水位与判据

命令：

```
python tools/check_environment.py
```

写这段时的实测：**85 项全绿**（六节 + 接线节）。全套 13 套自检合计约 1150 项。

判据（**不是水位**，低于即说明规则被改坏）：术语表覆盖率总 ≥ 50%；
靠拢步长两种读法都必须能算；`ALL` 掩码必须生效；地穴墙必须切成 2 片。

种类从 19 种顶到 20 种，多出 `tile_act48side` 未记进 `KNOWN_GAPS`。
