# 远程敌人：边走边打，不永久停（2026-09-15 定案）

> **坐标口径**：本文坐标为 **MAA 标准**（原点左上、y 向下），图 1-7（11×7）。
> 2026-09-16 之前写的是旧编号，现已换过；(2,3)、(3,3) 恰好是 `y=3` 的不动点，故看着没变。

## 一、改的是什么

`ak_tactic/battle/sim.py` 的推进块原来是：

```python
if e.alive and not e.leaked and not e.pending_reborn \
        and self._enemy_target(e) is None:      # ← 锁到目标就不推进
    e.advance(dt, self.speed_scale)
```

`applyWay == "RANGED"` 的敌人一旦在射程内锁定干员，就**永久中止路线推进**，
站在射程边缘打到死。现在改成：**推进与索敌解耦**——敌人照旧开火，但只在
"攻击动作"期间原地停一下（`attack_pause`），动作一结束继续走。

落点：

| 文件 | 改动 |
|---|---|
| `ak_tactic/battle/unit.py` | `EnemyUnit.attack_pause` 字段；`advance()` 里新增早退分支 |
| `ak_tactic/battle/sim.py` | `enemy_windup` 参数（默认 0.5s）；推进块统一递减 `attack_pause`；`_enemies_attack` 出手时置位 |
| `tools/check_battle.py` | 新增第 [9] 节，把这条规则与它的敏感性一起钉住 |

## 二、为什么改：1-7 的实机录像说旧读法不成立

| | 旧读法（永久停） | 实机录像 |
|---|---|---|
| 结果 | 胜利 343.9s | 胜利 ≈140s |
| 击杀 | 37 / 41 | **41 / 41** |
| 漏怪 | **4** | **0** |
| 干员阵亡 | 3 | 0 |

录像内容：怒潮凛冬 精英2 60 级 **单干员**站 (2,3) 朝右，2 倍速代理指挥回放。

推理链：她 `rangeId = 1-1`，站 (2,3) 朝右只覆盖 **(2,3) 与 (3,3)** 两格，
而 (3,3) 是障碍、敌人不经过——她的输出**完全依赖敌人必经 (2,3)**。
1-7 里有 4 只「鸡尾酒投掷者」（`RANGED`、`rangeRadius = 1.75`）。
若"锁到目标即中止推进"成立，它们会停在距她 1.75 格处，**落在 (3, 2) 这类
她够不着的格子里**，她永远打不到，必然漏 4 只。录像却是 **0 漏**。

⇒ 旧读法被证伪。与博士确认后定为：**不会永久停，边走边打，只在攻击动作
期间停一下**。

顺带说明：这条修改**不影响**当初引入旧读法的那个理由。那条理由是"只让被
阻挡的敌人出手，会让不可阻挡的飞行单位从干员身边走过去一下不打"——现在
敌人照样开火，只是不再因此站住。

## 四、0.5 秒是假设，不是实测

敌人的攻击动画长度不在 gamedata 里，所以 `enemy_windup` 是模拟器给的值。
敏感性扫描（已固化进 `check_battle.py` 第 [9] 节）：

```
攻击动作 0.00s：137.0s  41 杀  0 漏
攻击动作 0.25s：137.0s  41 杀  0 漏
攻击动作 0.50s：137.0s  41 杀  0 漏     ← 默认
攻击动作 1.00s：137.0s  41 杀  0 漏
反例  60.00s（≈永久停）：429.7s  37 杀  4 漏  3 阵亡   ← 旧读法
```

结论在 0–1 秒区间内不随这个数变化；而把动作时间拉到 60 秒正好退回被证伪的
旧读法——这条反例守卫保证该检查有分辨力，不是空跑。

1. **即便在旧读法下，`docs/srx8-solution.md` 里那些"余量 79% / 92%"的结论
   也已经不成立**——那份文档写在 15:41，其后的改动已使它失效。它现在的价值
   只剩"记录过哪条思路"。
2. 新读法下敌人不再堆在停点上挨打，**SR-EX-8 的难度重心整个变了**：原先
   "让 BOSS 停在覆盖范围里"的整套思路建立在敌人站桩上，已随之失效。
