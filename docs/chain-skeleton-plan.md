## 四、★ 本轮只交**一条键的判据**：`chain.atk_scale`

**断言**（方向）：治疗链上，第 2 跳的治疗量 = **0.75 ×** 第 1 跳（**严格递减**，且首跳＝满量）。

**判据三件套**：

* **计数可见**：判据必须打印**逐跳治疗量序列**（不是只打印一个数）——只比总数会让「衰减发生在哪一跳」不可见。
* **合成反例（可证伪的红条件，先写死）**：
  * （a）把衰减系数当**每次乘基准**（每跳都 ×0.75）⇒ 第 3 跳 = 0.75 ≠ 预期 ⇒ **必须红**；
  * （b）把衰减**丢掉**（每跳 = 1.0）⇒ 第 2 跳 = 1.0 ⇒ **必须红**；
  * （c）把衰减方向弄反（越跳越高）⇒ **必须红**。
* **反向守卫**：把 `chain.atk_scale` 置 1.0（等价于无衰减）时判据**必须红**，且退出码非 0。

#### 7.2.1 前置未定项：`0.75` 是哪种东西，还没定

> **「0.75」这个数本身是哪种东西，还没定** —— 它可能是
> **① 衰减系数（降到 75%）**，也可能是 **③ 每跳倍率（每跳都是 0.75 × 首跳）**。
>
> **这一条之所以「前置」**：`n=2` 的观测值在 **三种**读法下**完全同值**（都是 `0.75 base`）——
> 所以 §四 那条断言（第 2 跳 = scale × 首跳）**数值上在三读法下都成立**。
> ★ **它既是「敢断言第 2 跳」的理由，也正是「它区分不出读法」的理由：同一件事的两面。**
>
> ⇒ **在 ③ 被排除之前，`n=3` 的判决条件是三联的（0.5625 ／ 0.5 ／ 0.75）**，
> 而不是「二选一 + 一个『都不是』的兜底」。

| 读法 | 一句话 | n=1 | n=2 | **n=3** | n=4 |
| --- | --- | --- | --- | --- | --- |
| ① 等比衰减（0.75 是衰减系数） | 每跳是上一跳的 75% | base | 0.75 base | **0.5625 base** | 0.421875 base |
| ② 等差衰减（每跳减 25% 首跳） | 每跳少 25% 首跳 | base | 0.75 base | **0.5 base** | 0.25 base |
| ③ **每跳倍率**（0.75 是倍率本身） | 每跳都是首跳的 75% | base | 0.75 base | **0.75 base** | 0.75 base |

★ **表里 n=2 那一列三行全同**——这就是「前置未定」的全部内容：**n=2 对区分读法零信息量**，
而 §四 的断言在这三行下都真。★ **分岔点仍然只有一个：n=3**（三值互不相等），
**但「n=3 该判成哪个」在 ③ 未被排除前不可能是二值的。**

★ **「某读法为真」时，要分开问它对「数值」与「解释」各有什么影响**（PM 通则 `msg-mu900bls-ft`）：

| **在哪个观测点上分岔** | **只看 n=3 一跳即可**（三读法在该跳互不相等，见 7.2 表）；**n=2 对区分读法零信息量**；**n=4 只用于确认斜率是否继续**（0.421875 ／ 0.25 ／ 0.75） |
| **读数从哪来** | ① **跨源**：能给出逐跳治疗量的第三方数据（现有的 DB 只有 `0.75` 一个数，**不够**）；② **实战**：实机线解锁后打一场带乌啾/明椒的关卡，抓逐跳治疗量痕迹（**现在拿不到**：实机线卡在同步弹窗）。⇒ **现有数据不够**，这一点必须写死，否则下一个人会以为「再查一次库就行」 |
| **判成 ① 等比的条件** | 第 3 跳 ＝ **0.5625 × 第 1 跳**（容差按痕迹打印刻度定，不许先写死） |
| **判成 ② 等差的条件** | 第 3 跳 ＝ **0.5 × 第 1 跳** |
| **判成 ③ 每跳倍率的条件** | 第 3 跳 ＝ **0.75 × 第 1 跳**（＝与第 2 跳同值） |
| **三个都不成立时** | ⇒ **第四种读法**（此时 §四 断言的**数值**也可能失效，必须回头重估） |
| **落地位置** | 只需改 `rios-sim/mech/chain.go` 的 `chainJumpScale`（现在的 `n ≥ 3 ⇒ ErrJumpUndetermined` 换成按读法计算），**判据与规格不许动** |

★ **第三个候选（③）是本实验最有价值的部分**：它说明「0.75」**可能不是衰减系数**而是**每跳倍率**——
**在它被排除之前，连「该在哪一跳读」这件事都不算定案**。
（读数拿不到是**等待**，读法没定是**分析**——前者等时间，后者现在就能想清楚，两件事要分开写。）

★★ **自我更正（留痕，不改旧话）**：本节上一版在这里写过「③ 会让 `n=2` 的断言也变成错的」。
**这句不准确**：③ 为真时第 2 跳**仍然是** `0.75 base` ⇒ §四 那条断言的**数值**照样成立，
