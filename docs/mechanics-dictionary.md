## 二、词典原文（判据，逐条照抄）

| 词条 | 定义 |
|---|---|
| 隐匿 | 不阻挡时不成为敌方攻击的目标 |
| 晕眩 | 无法移动、阻挡、攻击及使用技能 |
| 冻结 | 无法移动、攻击及使用技能（通过寒冷触发）；敌方被冻结时，法术抗性-15 |
| 寒冷 | 攻击速度下降30，如果在持续时间内再次受到寒冷效果则会变为冻结 |
| 抵抗 | 晕眩、寒冷、冻结、恐惧、诱导等异常状态的持续时间减半；麻痹等状态每5秒流失1层（同名效果不叠加） |
| 神经损伤 | 神经损伤累计至1000时，受到1000点真实伤害并晕眩10秒 |
| 沉睡 | 无敌且无法行动 |
| 束缚 | 无法移动 |
| 停顿 | 移动速度降低80% |
| 侵蚀损伤 | 侵蚀损伤累计至1000时，永久降低100点防御力并受到800点物理伤害 |
| 折射 | 生效时，法术抗性+70 |
| 近地悬浮 | 无法被阻挡或近战攻击 |
| 灼燃损伤 | 灼燃损伤累计至1000时，10秒内降低20法术抗性并受到1200点法术伤害 |
| 凋亡损伤 | 凋亡损伤累计至1000时，15秒内无法开启技能，每秒损失1点技力并受到100点法术伤害 |
| 异常状态 | 包括晕眩、寒冷、冻结等 |
| 迷彩 | 不阻挡时不成为敌方普通攻击的目标（无法躲避溅射类攻击） |
| 屏障 | 可以吸收一定数值的伤害 |
| 战栗 | 被阻挡后无法进行普通攻击 |
| 恐惧 | 无法被阻挡并四散逃跑 |
| 脆弱 | 受到的物理、法术、真实伤害提升相应比例（同名效果取最高） |
| 浮空 | 变为空中单位，无法移动、攻击及使用技能；对重量大于3的单位持续时间减半 |
| 狂躁损伤 | 狂躁损伤累计至1000时，15秒内攻击速度+50，但每秒受到100点真实伤害（每次攻击时提升50，最多600） |
| 起飞 | 不阻挡地面敌人且不会被地面敌人攻击，可以阻挡飞行敌人 |
| 麻痹 | 每层麻痹可以使敌人在普通攻击时打断本次攻击，上限3层；麻痹未被消耗时持续时间无限，拥有抵抗的单位每5秒流失1层 |
| 元素脆弱 | 受到的元素伤害提升相应比例（同名效果取最高） |
| 元素损伤 | 包括神经损伤、侵蚀损伤、灼燃损伤、凋亡损伤、狂躁损伤 |

## 三、落点与实施顺序

**落点：Go（`rios-sim/`）。** 理由有两条，都是已经发生的事实而不是偏好：
默认模拟器已由博士裁定切到 Go（见项目记忆）；Python 的 `ak_tactic/battle/` 正被
另一会话逐轮摘除（`AK-TACTIC-进度.md` 3.29–3.42）。数据流是
**Python 解析/规格（`ak_tactic/simgo/spec.py`）→ Go 引擎 → 对拍**，所以每条机制
要动三处：规格带字段、Go 消费、自检/对拍给判据。

| 优先级 | 条目 | 理由 |
|---|---|---|
| P1 | 寒冷（攻速 −30 ＋「再次寒冷→冻结」）、抵抗（异常时长减半、麻痹每 5 秒流失 1 层） | 改的是**已有的控制链**（Go 已有冻结/眩晕/停顿/束缚），一条通则覆盖大片引用 |
| P1 | 冻结期间「敌方法术抗性 −15」 | 冻结已在 Go 里，缺的只是这条数值 |
| P2 | 脆弱 / 元素脆弱 | 伤害公式的一环（`受到…伤害提升相应比例，同名取最高`） |
| P2 | 元素损伤体系：神经 / 侵蚀 / 灼燃 / 凋亡 / 狂躁 ＋ 元素抗性 | 五条共用一个"累计到 1000 触发"的状态机＋五套结算；工程最大 |
| P3 | 麻痹、战栗、恐惧、沉睡、浮空 | 控制类补全，各自有独立判据（打断本次攻击 / 被阻挡后不能普攻 / 四散逃跑 / 无敌且无法行动 / 转空中单位） |
| P4 | 自身状态：隐匿、迷彩、起飞、折射、近地悬浮 | 前四条在**我方**单位上，折射与近地悬浮是**敌人侧独有** |

## 四、诚实登记（不许装成 0）

* **寒冷**：Go 侧零实现；Python 侧 2026-09-19 已在 `ak_tactic/battle/unit.py` 补了
  攻速折减（`COLD_ASPD_DOWN`、`enemy.effective_interval()`），但那一层正在被摘除，
  **真正的落点仍是 Go**；「再次寒冷→冻结」两处都没做。
* **冻结法抗 −15**：两处都没做（词典同一条 tooltip 里）。
* **狂躁损伤 / 折射 / 近地悬浮**：干员侧引用为 0，属于纯敌人侧机制。
* 本表的「引用数」是**首过**统计，词在正文里出现即计；某条真要判定"这一关会不会
  走到"，必须回到具体关卡与出怪表，不能用这个词频代替。
