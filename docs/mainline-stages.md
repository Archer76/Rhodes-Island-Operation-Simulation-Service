### 6.1 三件分别是怎么凑齐的

| 件 | `main_01-07` 的来源 | 落在哪 | 判据 |
| --- | --- | --- | --- |
| **① 关卡数据** | `python -m ak_tactic stage main_01-07 --json` → `out/ml-stage-01-07.json`（46,948 B） | 缓存 `data/gamedata/map.ark-nights.com/levels/obt/main/level_main_01-07.json` | 命令 **rc=0** 且 JSON 里 `level_id`/`map`/`spawns` 齐 |

| **③ 基线** | `python tools\golden_go.py --extend` | `fixtures/golden_go.json` 的 `plan-main-01-07.json` 条目 | 判决四数 + `spec_sha` 逐项一致；条目**自带仪器身份** |

★ **发现的两处缺口（本次已补）**：

1. **夹具原先住在 `out/`** —— 而 `out/` 是易失目录（`.gitignore` 里有它）。
   通告 #6 四已裁定「判据集进版本控制，`fixtures/` 是唯一判据集」，
   所以 `out/search-17.json` 必须迁进 `fixtures/`。**本次迁入，字节一致**
   （两侧 sha256 同为 `03527C5B7402BD19831DD6CBF100CF7594CC2A98AC30AC0581411ABD36A11AAE`）。
2. **它原先没有 Go 基线** —— `fixtures/golden_go.json` 里**没有** `main_01-07` 这一条。
   PM 台账里那句「四项全归零」来自 `tools/gate_ledger.py`（**py ↔ go 对拍**），
   而**对拍已按裁定不作验收**（09-19），且它的台账**只在 `out/*.json` 里扫作业**。
   ⇒ 「有作业」不等于「有基线」。**本次用 `--extend` 补录。**

### 6.2 固化成命令（换一关只改一个变量）

```powershell
# 0) 钉住仪器（不钉会静默落到工作树里的预编译 exe，读数不可比）
$env:RIOS_SIM_BIN = "out/acceptance/rios-sim-12f35f7.exe"

# 1) 关卡数据（取数 + 落缓存；rc=0 即取到）
python -m ak_tactic stage main_01-07 --json > out\ml-stage-01-07.json

# 2) 夹具（作业）：search 产出并直接写进判据集目录
python -m ak_tactic search main_01-07 --box fixtures\roster_max_modelled.json `
       --max-ops 2 --save-plan fixtures\plan-main-01-07.json

# 3) 判决（rc 就是这一关的验收码）
python -m ak_tactic verify --plan fixtures\plan-main-01-07.json --json > out\ml-verify-main-01-07.json

# 4) 基线（**先验已有条目逐项一致，再并入新的**；rc=0 才收）
python tools\golden_go.py --extend

# 5) 复核：与基线逐项比（rc=0 = 不漂移）
python tools\golden_go.py --check
```

★ 第 4 步的 `--extend` **不是**「顺手把新的塞进去」：它**先跑全部已有条目**，
**只要有一份与基线不一致就整体拒绝并 rc=1**（本次输出：
`已有 20 份逐项一致；新增 3 份已并入`）。这条正是「扩展不许顺手掩盖改动」。

### 9.7 一条修掉的自身缺陷（默认环境下的假红）

`tools/mainline_devices.py` 原先**在默认环境下会崩**：本机 python 的 `sys.stdout.encoding`
默认是 **gbk**，而它要印 `✓`/`❌` ⇒ 印最后那行总结时抛 `UnicodeEncodeError`、**rc 变 1**。

⇒ **危险的不是崩溃，是崩溃伪装成结论**：`rc=1` 会被读成「有违规」，而它其实死在印总结那一行。
**我此前每次跑都恰好设了 `PYTHONIOENCODING`，所以从没看见过**——这正是「默认路径最危险」。

处置三条：① 入口 `sys.stdout.reconfigure(errors="backslashreplace")`（**只放宽错误处理器、不改编码**）；
② 判定词改 **ASCII 打头**（`[OK]` / `[FAIL]`），判据结果不许只活在字形里；
③ 给「崩了」留**与业务态不重叠**的退出码 **5**（0=跑完／1=取数失败／2=守卫红／5=自己崩了）。

实测（`PYTHONIOENCODING` 已清空）：正常 → **rc=0**；构造崩溃（写不存在的盘）→ **`[CRASH]` + rc=5**。
